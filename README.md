# 재획 알리미 데스크톱 앱 (Windows)

메이플스토리 재획 알리미의 Windows 프로그램을 받는 곳이에요.
게임 화면을 보고 **스킬 쿨타임 · 룬 · 잠수 · 도핑 · 부스터**를 감지해 알림을 보내 줘요.

웹에서 바로 쓰려면 👉 **https://maple-alert.pages.dev**

## 다운로드

**[최신 버전 받기](https://github.com/heomne/maple-alert-releases/releases/latest)** → `MapleAlert-Setup-x.y.z.exe`를 받아 실행하면 설치돼요.

- Windows 10 이상 · 무료 · 약 110MB
- 설치할 때 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 눌러 주세요.

## 웹 버전과 다른 점

| | |
|---|---|
| **메이플 창 자동 연결** | 공유할 창을 고르지 않아도 [화면 공유 시작]만 누르면 메이플 창을 찾아 바로 감지해요. |
| **게임 위 오버레이 알림** | 게임 화면 위에 타이머와 알림이 투명하게 떠요. 클릭은 게임으로 그대로 통과해요. |
| **창을 내려도 정확하게** | 알리미 창을 최소화하거나 다른 창에 가려도 감지와 알림이 늦어지지 않아요. |
| **트레이에서 계속 실행** | 창을 닫아도 작업 표시줄 트레이에서 알림을 이어서 보내요. 닫기 버튼 동작(매번 묻기 · 트레이로 내리기 · 종료)은 바꿀 수 있어요. |

## 업데이트

- **화면 · 기능:** 웹에 새 버전이 나오면 프로그램에도 바로 반영돼요. 다시 설치하지 않아도 돼요.
- **프로그램 자체:** 새 버전은 자동으로 받아 두고 알려 드려요. 트레이 메뉴의 [업데이트하고 다시 시작]으로 적용하거나, [업데이트 확인]으로 직접 확인할 수 있어요.
- 버전별 바뀐 점은 [Releases](https://github.com/heomne/maple-alert-releases/releases)에서 볼 수 있어요.

## 알아 두세요

- 설정은 웹과 따로 저장돼요. [불러오기/내보내기]로 옮길 수 있어요.
- 게임 화면은 PC 안에서만 분석하고 밖으로 보내지 않아요.
- 화면을 보고 알려 주기만 해요. 키 입력 같은 게임 조작은 하지 않아요.
- 이 저장소는 설치 파일 배포용이에요. 문의 · 제보는 앱의 설정 → [제보하기]를 이용해 주세요.
